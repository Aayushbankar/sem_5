### A4. Breach response runbook
1. **Contain** (revoke keys, isolate store — target ≤15 min)
2. **Assess** (what leaked, whose, how many records)
3. **Notify** (affected users within 72 h — draft the message)
4. **Report** (regulator if required; write incident log)
5. **Remediate** (fix root cause; re-run P12 risk matrix)
