# P09 — AI Social-Media Campaign & Promotional Content

**Subject:** AI Product Design | **Unit:** 4 | **Approx. Hrs:** 4
**PrO (verbatim):** *Design AI-based social media campaign and generate promotional content.*

---

## 1. Objective
- Plan a **2-week campaign** for StudyMate around the GTU exam season (target: diploma students on Instagram/YouTube/WhatsApp).
- Define **platforms, funnel, KPIs** and a content calendar.
- **Generate 5 promo content drafts** (using AI tools like ChatGPT/Canva AI) and annotate why each works.

## 2. Campaign plan (filled)

### 2.1 Context & goal
- **Trigger:** GTU semester exams start in ~3 weeks → spike in "last-minute revision" search demand.
- **Goal (SMART):** 10,000 reach, 1,000 free-signups, 20% first-week retention, <₹3 cost per signup.

### 2.2 Platform strategy

| Platform | Role in funnel | Content format | Frequency |
|---|---|---|---|
| **Instagram (Reels)** | Top of funnel — awareness | 20–30 s "before/after" revision reels, quiz hook | 5×/week |
| **YouTube (Shorts)** | Awareness + trust | "I failed the mock → StudyMate fixed it" vlog format | 3×/week |
| **WhatsApp (referral)** | Middle/bottom — activation | "Exam in 10 days" checklist + shareable score cards | 2×/week |
| **Landing page / email** | Bottom — conversion | Free plan offer + 3-day revision email sequence | 1×/week |
| **College ambassadors** | All stages (trust multiplier) | Campus groups, class demos | Ongoing |

### 2.3 Funnel (AIDA) with KPIs

```
Awareness   →  Interest  →  Desire  →  Action
Reels/Shorts   Profile→link  Testimonials  Free signup
 Reach 10K      Saves 800    Trial uploads   Signups 1,000
 CTR 2%       Shares 300     600             Conv 25%
   │              │             │                │
   └──────────────┴─────────────┴────────────────┘
        each stage feeds the next; track with UTM links
```

| Stage | Metric | Target |
|---|---|---|
| Awareness | Reach, impressions, views | 10,000 reach |
| Interest | Saves, shares, profile visits | 800 saves |
| Desire | "Trial upload" events, testimonials shown | 600 trial uploads |
| Action | Free sign-ups | 1,000 (conv. ≈ 25% of trial) |
| Retention (post-exam) | D7 return + referral | 20% D7; 200 referrals |

## 5. Field-by-field explanation (how to redo for your idea)
- **Funnel stages (AIDA)** — Awareness → Interest → Desire → Action → (Retention). Name one metric per stage so the campaign is measurable end-to-end.
- **Platform roles** — don't post the same thing everywhere. Instagram = *attract*, YouTube = *trust*, WhatsApp = *activate*. Each platform earns its place by a funnel role.
- **Hook discipline** — the first 3 seconds decide a reel's fate; write the hook first, always, and put it on line one of every draft.
- **CTA discipline** — one call-to-action per asset. "Link in bio" is fine *if* the link lands on a page matching the ad (free plan, one upload).
- **KPI attribution** — use UTM/short links per platform so you can answer *"which platform drove signups?"* — otherwise the calendar is theatre.
- **AI generation** — the syllabus expects you to *use* generative AI here: keep your prompt drafts + the raw AI output + your edits in the report appendix (shows the process, examiners love it).

## 7. Viva Q&A
1. **What is a funnel?** — The stage-wise path from stranger to user (Awareness → Interest → Desire → Action); each stage has its own metric and content.
2. **Why 3 seconds?** — Reels/Shorts skip-rate is brutal; the hook (first 3 s) determines whether the rest gets watched.
3. **What's a "dark pattern" you must avoid here?** — Misleading hooks ("I failed…" when you didn't), fake testimonials, or pretending free = unlimited. It kills trust and violates P11 ethics.
4. **How do you know the campaign worked?** — Compare the funnel KPIs to targets and the signup source per platform (UTM links) — not by likes.
