## 🛠 Requirements
- **No code to run** — all practicals are document-based product-design deliverables.
- Free accounts: **Glide** (P10 prototype), **Canva AI** (P09 content), **OpenAI Playground / ChatGPT** (P01/P09 experimentation), **Figma** (P05 mock-ups), **Gamma** (presentations).
- Phone with camera for the P10 demo video (2–3 min).
- Optional: Google Colab / Teachable Machine for P02–P03 model demos.

## ⚠️ Exam tips
- **Unit 4 (22%) is the heaviest** — master the 4 social-media risks (deepfakes, fake news, bots, algorithm manipulation) with examples and mitigations.
- Every unit exam answer should reuse **StudyMate** — the examiner rewards one consistent, worked example.
- "Write short notes" favourites: AI tool vs product, GenAI vs Analytical AI, 4 system components, MoSCoW, BMC 9 blocks, token concept, personal vs sensitive data, DPDP basics, prompt injection, risk checklist.
- Practical viva: know the *why* behind each template field, not just the filled values — expect "where did this field come from?" questions.
