- [ ] Screenshot: `mininet> s1 dpctl dump-flows` — **full output**
- [ ] Annotate **one flow entry** with explanation:
  ```
  cookie=0x0, duration=12.345s, table=0, n_packets=6, n_bytes=504,

  ```

- [ ] Written explanation (½ page):

## 6. Conclusion / Analysis (1 page)
- [ ] **What Mininet is** — network emulator using Linux namespaces + veth pairs
- [ ] **What SDN is** — control plane (controller) separated from data plane (switches)
- [ ] **OpenFlow role** — southbound protocol between controller and switches
- [ ] **Namespaces purpose** — each host gets isolated network stack (own IP, routes)
- [ ] **What `pingAll` proves** — end-to-end L2/L3 connectivity across emulated SDN fabric
- [ ] **Controller vs Switch** — controller = brain (computes paths), switches = dumb forwarders per flow rules
- [ ] **Learned flow significance** — first packet triggers controller; rest use installed flow = SDN in action

## Screenshot Tips
- Use **VirtualBox View → Virtual Screen 1 → Take Screenshot** (Host+E)

- Annotate with arrows/text (Flameshot, Greenshot, or PowerPoint)
- Keep terminal font readable (14+ pt) — increase in VM terminal preferences before recording
- Capture **full width** of terminal so commands + output both visible
