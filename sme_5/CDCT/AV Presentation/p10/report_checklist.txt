## 6. Image vs Container — Written Explanation (½ page)
- [ ] **Image** = read-only template (layers), created by `docker build`
- [ ] **Container** = running instance of an image, created by `docker run`
- [ ] **Layered build** = each Dockerfile instruction adds a layer; cached on rebuild
- [ ] **Port publishing** = `-p HOST:CONTAINER` maps host port to container port

## 7. Cleanup Evidence
- [ ] Terminal: `docker stop ... && docker rm ...` commands
- [ ] Terminal: `docker ps -a` — **no containers** (or only exited ones)
- [ ] Terminal: `docker images` — only base images remain (or clean)
