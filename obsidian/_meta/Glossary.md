# 📖 Glossary

Key terms across all Semester 5 subjects, alphabetically. Click any wikilink to jump to the relevant note.

---

## A

- **Agentic AI** — AI systems that autonomously plan, reason, and take actions using tools. → [[Unit 5 — AI Application Development Agentic AI]]
- **API (Application Programming Interface)** — A set of protocols for building software; in AI context, APIs from OpenAI/Google provide LLM access. → [[Unit 3 — AI Product Strategy and OpenAI Integration]]
- **Avalanche Effect** — A tiny change in input produces a completely different hash output (~50% bits flip). → [[Unit 1 — Foundations of Decentralization]]

## B

- **BIP39** — Bitcoin Improvement Proposal for mnemonic seed phrases (12/24 words). → [[P06 — Wallets Mnemonic Bip39]]
- **Bitcoin** — First cryptocurrency (2009), uses Proof-of-Work consensus. → [[Unit 2 — Bitcoin and PoW]]
- **Blockchain** — A distributed, immutable ledger of transactions linked by cryptographic hashes.
- **Blynk** — IoT platform for building mobile dashboards for ESP32/Arduino. → [[P12 — Blynk Two Way Dashboard]]
- **Business Model Canvas** — A strategic management template for developing business models. → [[P07 — Business Model Canvas]]
- **Byzantine Generals Problem** — A thought experiment about achieving consensus among distributed, potentially faulty nodes. → [[Unit 1 — Foundations of Decentralization]]

## C

- **CAP Theorem** — In distributed systems, you can only guarantee 2 of 3: Consistency, Availability, Partition tolerance. → [[Unit 1 — Foundations of Decentralization]]
- **Chain-of-Thought (CoT)** — Prompting technique that elicits step-by-step reasoning from LLMs. → [[Unit 4 — Prompt Engineering Techniques]]
- **CloudSim** — Java-based simulation toolkit for modeling cloud computing environments. → [[P08 — Cloudsim Secure File Sharing]]
- **Consensus Mechanism** — Protocol by which blockchain nodes agree on the state of the ledger (PoW, PoS, BFT).
- **Container** — Lightweight, isolated environment for running applications (Docker). → [[P10 — Docker First Container]]

## D

- **DAO (Decentralized Autonomous Organization)** — An organization governed by smart contracts and token holder votes.
- **Data Center** — A facility housing computing infrastructure with defined tiers (I–IV). → [[Unit 3 — Data Center Architecture]]
- **Dataview** — Obsidian plugin for querying notes as a database using frontmatter metadata.
- **Design Thinking** — Human-centered approach to innovation (Empathize → Define → Ideate → Prototype → Test). → [[Unit 2 — Design Thinking and Human Centred AI]]
- **DHT Sensor** — Digital Humidity and Temperature sensor (DHT11/DHT22) for IoT. → [[P06 — Dht Temperature Humidity Sensor]]
- **Docker** — Platform for developing, shipping, and running applications in containers. → [[P10 — Docker First Container]]

## E

- **ERC-20** — Ethereum token standard defining a common interface for fungible tokens. → [[P08 — Erc20 Token]]
- **ESP32** — Dual-core microcontroller with built-in Wi-Fi and Bluetooth for IoT. → [[Unit 3 — ESP32 and Arduino IDE Development]]
- **Ethereum** — Blockchain platform supporting smart contracts and DApps. → [[Unit 3 — Ethereum and Smart Contracts]]
- **EVM (Ethereum Virtual Machine)** — Runtime environment for Ethereum smart contracts.

## F

- **Few-Shot Prompting** — Providing a few input-output examples in the prompt to guide LLM behavior. → [[P06 — Zero Shot Few Shot Role Based]]

## G

- **Gas** — Unit measuring computational effort required to execute operations on Ethereum.
- **GDPR** — General Data Protection Regulation (EU) for data privacy.
- **Generative AI** — AI that creates new content (text, images, code) from learned patterns. → [[Unit 1 — Foundations of AI and Generative AI]]

## H

- **Hallucination** — When an LLM generates confident but factually incorrect information. → [[P04 — Llm Capabilities Limitations Hallucinations]]
- **Hash Function** — Mathematical function producing fixed-length output from any input. → [[Unit 1 — Foundations of Decentralization]]
- **Hyperledger Fabric** — Enterprise-grade permissioned blockchain framework by Linux Foundation. → [[P09 — Case Study Public Vs Private Hyperledger]]

## I

- **IaaS / PaaS / SaaS** — Cloud service models (Infrastructure / Platform / Software as a Service). → [[Unit 1 — Introduction to Cloud Computing]]
- **IoT (Internet of Things)** — Network of physical devices embedded with sensors, software, and connectivity. → [[Unit 1 — Introduction to IoT]]

## L

- **LLM (Large Language Model)** — Neural network trained on massive text data for language understanding and generation. → [[Unit 2 — Basics of Large Language Models]]

## M

- **Merkle Tree** — Binary hash tree used for efficient data verification in blockchains. → [[P04 — Merkle Tree]]
- **Mininet** — Network emulator for SDN (Software-Defined Networking) research. → [[P05 — Mininet Virtual Sdn Lab]]
- **MinIO** — High-performance, S3-compatible object storage. → [[P09 — Minio Secure Object Storage]]
- **MQTT** — Lightweight publish/subscribe messaging protocol for IoT. → [[P08 — Esp32 Mqtt Publisher]]
- **MVP (Minimum Viable Product)** — Product with just enough features to satisfy early users. → [[P06 — Mvp Feature Prioritization]]

## N

- **Nonce** — A number used once in mining; miners vary it to find a hash below the difficulty target. → [[P05 — Nonce Mining Difficulty]]

## O

- **OpenStack** — Open-source cloud computing platform for IaaS. → [[P01 — Openstack Architecture]]

## P

- **PIR Sensor** — Passive Infrared sensor for detecting motion. → [[P05 — Pir Ldr Sensor Interface]]
- **Proof-of-Work (PoW)** — Consensus mechanism requiring computational work to validate blocks. → [[Unit 2 — Bitcoin and PoW]]
- **Proof-of-Stake (PoS)** — Consensus mechanism based on staking cryptocurrency to validate blocks.
- **Prompt Engineering** — The art of crafting effective prompts to guide LLM outputs. → [[Unit 3 — Prompt Engineering Fundamentals]]

## R

- **RAG (Retrieval Augmented Generation)** — Technique combining document retrieval with LLM generation. → [[P11 — Document Qa Basic Rag]]
- **RBAC** — Role-Based Access Control for cloud resource management. → [[P02 — Cloud Organization Rbac]]
- **Re-entrancy Attack** — Smart contract vulnerability where a function is called recursively before state updates.

## S

- **SHA-256** — Secure Hash Algorithm producing 256-bit (64 hex char) output; used in Bitcoin. → [[Unit 1 — Foundations of Decentralization]]
- **Smart Contract** — Self-executing code deployed on a blockchain. → [[Unit 3 — Ethereum and Smart Contracts]]
- **Solidity** — Programming language for writing Ethereum smart contracts. → [[P07 — Smart Contract Evm]]

## T

- **ThingSpeak** — IoT cloud platform for data aggregation and visualization. → [[P10 — Thingspeak Http Temperature]]
- **Transformer** — Neural network architecture based on self-attention; foundation of modern LLMs. → [[Unit 2 — Basics of Large Language Models]]

## U

- **UTXO** — Unspent Transaction Output model used by Bitcoin for tracking balances. → [[Unit 2 — Bitcoin and PoW]]

## V

- **VirtualBox** — Free, open-source hypervisor for x86 virtualization. → [[P03 — Install Virtualbox Linux Vm]]
- **Virtualization** — Creating virtual versions of hardware, OS, or resources. → [[Unit 2 — Virtualization and Hypervisors]]

## Z

- **Zero-Shot Prompting** — Asking an LLM to perform a task without any examples. → [[P06 — Zero Shot Few Shot Role Based]]
